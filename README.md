# 와플스튜디오 24.5기 Product Engineering 세미나

내 주변 문제를 해결할 수 있는 제품을 모바일 앱으로 만들어보는 과정을 통해, 개발 전 과정에 대한 기본적인 이해를 갖춰보는 것을 목표로 합니다.

## 시작하기

1. [pe-seminar-2026-template](https://github.com/WaffleStudio24-5/pe-seminar-2026-template)에서 **Use this template**으로 본인 계정에 repo를 만들어주세요. 이름은 앱 이름 등 자유롭게 설정/변경 해주시면 됩니다. Public을 권장하지만 private도 괜찮습니다.
2. 만든 repo의 Settings → Collaborators에서 `parkchaehyun`을 추가해주세요.

## 과제 제출

과제마다 새 branch에서 작업하고, 본인 repo의 `main`으로 PR을 올린 뒤 reviewer로 `parkchaehyun`을 지정해주세요.
각 과제마다 피드백은 PR 리뷰를 통해 드리고, 리뷰가 승인 되면 직접 merge하시면 됩니다.

API key 같은 secret은 commit하지 말고, `.gitignore`에 추가 되어있는 `.env`에 저장해주세요.
